# Additive Cipher\n\n## Introduction\nThe Additive Cipher is one of the simplest substitution ciphers. Each letter is replaced by the letter a fixed number of positions later in the alphabet. Caesar cipher is its special case with key 3.\n\n## Encryption\nFor key k and plaintext letter p (0-25): C = (p + k) mod 26\n\n## Decryption\nP = (C - k) mod 26\n\n## Security\nOnly 26 possible keys, so it is broken instantly by brute force.
